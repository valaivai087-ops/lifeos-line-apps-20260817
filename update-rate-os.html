今天，送給自己的3個小進步

不用一次改變全部。今天只選1～3件做得到的小事，讓自己慢慢靠近想成為的模樣。

給正在努力的你

也許你已經很努力，卻還是覺得自己停在原地。請先給自己一點溫柔：過去的方法曾經陪你走到這裡，現在可以試著學會新的走法。每一次願意更新，都在替未來打開一扇窗。

更新速度＝多快發現舊Model失效＋多快取得新資訊＋多快修正Model＋多快投入行動＋多快取得Feedback＋多快再次修正。

概念公式用於思考與行動，並非經實證校準的量化定律。

每一小步，都算數

你寫下的每一次反思、做出的每一個改變，都會留下成長的足跡。Error → Update → Action → Feedback，讓經驗陪你走向下一步。

六種值得訓練的速度

看見錯誤 → 承認錯誤 → 找到原因 → 修改Model → 重新行動 → 取得Feedback後再次更新。

60個陪你成長的小練習

從理解自己，到真的跨出一步。機制層30項＋行動層30項，選一個最貼近此刻心情的練習就好。

每天5分鐘，和自己好好說話

忙了一整天，也留5分鐘給自己。慢慢寫、慢慢想，今天的感受值得被聽見。紀錄會依日期保存。

每週15分鐘，把自己重新接住

這週辛苦了。留下帶給你力量的事，放下讓你耗盡的事。用Keep／Stop／Update／Add整理心情，再為下週留一個小小的可能。

完整更新循環

High Agency × 低／高更新速度
情境Low Agency／低更新High Agency／高更新

低更新路徑：威脅 → 防衛 → 否認 → 怪環境 → 沿用舊Model → 誤差擴大 → 系統僵化。

高更新路徑：辨識差異 → 承認Error → 新資訊 → 修正 → 小測試 → Feedback → 再修正 → 能力與選項增加。

更新複利 × Model迭代週期

A遇到問題，防衛3個月、思考2個月、嘗試一次後放棄；一年可能只完成1次循環。B在24小時內辨識Error，提出假設、Micro Experiment、Feedback、Retest與再修正；一年可能完成數十至數百次小型循環。

長期差距＝更新循環次數 × 每次更新品質 × 時間複利。

1%更好的Model → 更好的Decision → 更好的Outcome → 更高品質Feedback → 更好的下一版Model。

1%與循環次數是原文概念示例，並不保證能力按同樣比例增長；更新品質與環境同樣重要。

有效方法連續成功3次，壓縮成Rule／Checklist／SOP；新證據出現時，再檢查適用期限。
