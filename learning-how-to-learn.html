📖 核心單字 × 輸出模型 / Vocabulary × Output Model

看到每個單字，先嘗試用它造一個句子，再看例句。這就是「輸出模型」的實踐！
Try to make a sentence first, then check the example — this is the Output Model!

🌱 字根遷移 / Root Transfer Model

一個字根推十個單字——這是「遷移模型」！看到生字時，先拆字根猜意思。
One root = ten words. When you see new words, guess from the root first!

⚙️ 高頻文法 / Grammar Essentials

學測必考文法重點——用「費曼模型」：你能用自己的話解釋這個規則嗎？
Key grammar for 學測 — Feynman Model: Can you explain the rule in your own words?
